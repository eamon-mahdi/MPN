How the shared OneDrive folder works
• All data is kept in mpn_clinic_data.json in the shared folder. OneDrive syncs it to everyone who has the folder.
• Saving is automatic (within ~2 seconds of any change). The app checks for colleagues' changes every 10 seconds and merges them in – several people can run the same clinic at once.
• If OneDrive ever creates a conflict copy (e.g. mpn_clinic_data-PCNAME.json), the app merges it automatically and moves it into Backups/.
• Each patient's letter is saved as a Word file in Letters/<clinic date>/. The secretary pack (all letters in one file + summary) goes there too.
• A daily backup is written to Backups/.
• Patient data never leaves NHS OneDrive and this computer. Check local information-governance approval before using with real patient data.
