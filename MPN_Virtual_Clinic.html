How the shared folder works
• All data lives in mpn_clinic_data.json in the shared folder; OneDrive syncs it to the team.
• Saving is automatic. Colleagues' changes are merged in every 10 seconds, so several people can run one clinic together.
• OneDrive conflict copies are merged automatically and moved to Backups/.
• Letters are saved as Word files in Letters/<clinic date>/, plus a secretary pack.
• A daily backup is written to Backups/.
• Check local information-governance approval before using with real patient data.
